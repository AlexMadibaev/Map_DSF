# Прогулка по GLB-карте

## Запуск

Самый простой способ — дважды нажать `Запустить карту.cmd`.

Или через терминал:

1. Установите Node.js 20.19+.
2. В этой папке выполните `npm install`.
3. Запустите `npm run dev`.
4. Откройте адрес, показанный в терминале (обычно `http://localhost:5173`).

Приложение использует только пользовательскую оптимизированную карту `public/map.glb`, полученную из `Тест++.glb`.

Карта весит 75,46 МБ и содержит 628 874 треугольника, 169 сеток и 50 изображений. Дополнительные quality/lite-вариации не используются.

На Vercel части карты и собранные assets кэшируются браузером на один год. HTML всегда проверяется на обновления. При замене модели нужно увеличить параметр `?v=` в `src/main.js`.

Физика использует отдельную скрытую модель `public/collision.glb` на 104 694 треугольника (около 152 КБ): игрок может стоять на поверхностях, упираться в препятствия, подниматься по геометрии и запрыгивать на сцену. В режиме полёта столкновения отключены.

Фоновая музыка запускается после нажатия «Начать», играет циклически и кэшируется браузером. На компьютере клавиша M включает/выключает звук, на телефоне используется кнопка «Звук».

Управление: WASD или стрелки — движение, мышь — обзор, пробел — прыжок/подъём, C или Ctrl — присесть при ходьбе, Shift — ускорение, Ctrl — снижение в полёте, двойной пробел или F — полёт, R — возврат на старт, Esc — освободить мышь.

Для модели на 1,8 млн треугольников используется облегчённый режим перемещения без предварительного построения тяжёлой физической сетки.
