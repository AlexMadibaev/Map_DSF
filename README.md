# Прогулка по GLB-карте

## Запуск

Самый простой способ — дважды нажать `Запустить карту.cmd`.

Или через терминал:

1. Установите Node.js 20.19+.
2. В этой папке выполните `npm install`.
3. Запустите `npm run dev`.
4. Откройте адрес, показанный в терминале (обычно `http://localhost:5173`).

Приложение использует только окончательную карту `public/map.glb`, полученную из `FINAL.glb`.

Карта весит 57,41 МБ и содержит 332 116 треугольников, 182 сетки и 43 изображения. Дополнительные quality/lite-вариации не используются.

Во время загрузки показываются скачанные мегабайты, полный размер файла и процент, включая мобильные браузеры без заголовка `Content-Length`.

Проект является устанавливаемым PWA. Service Worker сохраняет карту и ресурсы в Cache Storage после первой загрузки. На Android используется кнопка «Установить приложение», на iOS — «Поделиться» → «На экран Домой». Приложение запрашивает постоянное хранилище, если браузер поддерживает Storage Persistence API.

На iOS отключены системные жесты масштабирования, выделение текста, контекстное меню и overscroll внутри приложения. Для стабильности WebGL на сенсорных устройствах используется pixel ratio 1 и отключён MSAA antialiasing; настольное качество рендера не изменяется.

На Vercel части карты и собранные assets кэшируются браузером на один год. HTML всегда проверяется на обновления. При замене модели нужно увеличить параметр `?v=` в `src/main.js`.

Физика использует отдельную скрытую модель `public/collision.glb`. В неё входят только базовая поверхность земли, сцена, техническая зона с мониторами и арка. Трибуны, сиденья, фестивальные зоны, вывески, декор и остальные конструкции не имеют столкновений. В режиме полёта столкновения отключены.

Фоновая музыка запускается после нажатия «Начать», играет циклически и кэшируется браузером. На компьютере клавиша M включает/выключает звук, на телефоне используется кнопка «Звук».

Управление: WASD или стрелки — движение, мышь — обзор, пробел — прыжок/подъём, C или Ctrl — присесть при ходьбе, Shift — ускорение, Ctrl — снижение в полёте, двойной пробел или F — полёт, R — возврат на старт, Esc — освободить мышь.

Для модели на 1,8 млн треугольников используется облегчённый режим перемещения без предварительного построения тяжёлой физической сетки.
